# Лабораторная работа 4. Проверка условий

## Задание 1. Управление кондиционером

По текущей и желаемой температуре вывести режим работы: «Охлаждение», «Нагрев» или «Выключен».

Файл: `task1.py`

## Задание 2. Расчет стоимости билета

По базовой стоимости билета и возрасту пассажира рассчитать цену с учётом возрастной скидки. При некорректных данных вывести «Ошибка».

Файл: `task2.py`

## Задание 3. Определение положения точки

По координатам `x` и `y` определить положение точки: начало координат, ось X, ось Y или одна из четырёх четвертей.

Файл: `task3.py`

## Задание 4. Проверка треугольника

По длинам трёх сторон определить, существует ли треугольник, и если да — его тип: равносторонний, равнобедренный или разносторонний.

Файл: `task4.py`

## Задание 5. Определение високосного года

По номеру года определить, является ли он високосным. При выходе за диапазон от 1 до 9999 вывести «Ошибка».

Файл: `task5.py`
