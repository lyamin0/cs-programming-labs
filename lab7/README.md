# Лабораторная работа 7. Обработка списков и таблиц

## Задание 1. Корректировка остатков

Пользователь вводит список целых чисел одной строкой через пробелы, обозначающих остатки товаров. Создать копию списка и заменить в ней все отрицательные значения нулями с помощью присваивания по индексу. Вывести исходный и исправленный списки.

Файл: `task1.py`

## Задание 2. Отбор значений

Пользователь вводит список целых чисел одной строкой через пробелы. С помощью спискового включения создать список квадратов положительных нечетных чисел из ввода, сохраняя порядок следования и повторения элементов. Вывести полученный список.

Файл: `task2.py`

## Задание 3. Индексы совпадений

Пользователь вводит список целых чисел одной строкой через пробелы, а на следующей строке — искомое целое число. Создать список индексов всех элементов, равных искомому числу, в порядке возрастания индексов с использованием `enumerate()`. Вывести полученный список индексов.

Файл: `task3.py`

## Задание 4. Суммы строк и столбцов

Пользователь вводит размеры таблицы $r$ и $c$, а затем $r$ строк по $c$ целых чисел в каждой. Сформировать два списка: суммы элементов каждой строки и суммы элементов каждого столбца, вычисляя суммы накоплением в циклах. Вывести оба списка.

Файл: `task4.py`

## Задание 5. Поиск в области таблицы

Пользователь вводит размеры таблицы $r$ и $c$, затем $r$ строк по $c$ целых чисел. Далее вводятся границы прямоугольной области (`row_start`, `row_end`, `column_start`, `column_end`) и искомое число. Найти все вхождения числа в заданной области и вывести индексы строки и столбца через пробел (или «Не найдено», если совпадений нет).

Файл: `task5.py`
