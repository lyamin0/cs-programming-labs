# Лабораторная работа 1. Основы Python

## Задание 1. Работа с переменными

Создать четыре переменные разных типов, вывести значение и тип каждой.

## Задание 2. Вычисление выражения

Вычислить выражение `(a + b) * c^2 - a div b + a mod b` при `a = 7`, `b = 4`, `c = 3`.

Файл: `task2.py`

## Задание 3. Расчет параметров площадки

По введённым длине и ширине вычислить площадь и периметр.

Файл: `task3.py`

## Задание 4. Перевод времени

Перевести введённое количество секунд в формат `HH:MM:SS`.

Файл: `task4.py`

## Задание 5. Расчет стоимости поездки
