# Лабораторная работа 6. Реализация численных алгоритмов

## Задание 1. Наибольший общий делитель

Пользователь вводит два целых числа `a` и `b` на отдельных строках. Если хотя бы одно число отрицательное или оба числа равны нулю, вывести «Ошибка». Для остальных значений найти наибольший общий делитель алгоритмом Евклида.

Файл: `task1.py`

## Задание 2. Проверка числа на простоту

Пользователь вводит целое число `n`. Определить, является ли оно простым, перебирая возможные делители до $\sqrt{n}$. Вывести «Простое» или «Не простое».

Файл: `task2.py`

## Задание 3. Разложение на простые множители

Пользователь вводит целое число `n`. Если $n < 2$, вывести «Ошибка». Разложить допустимое число на простые множители и вывести их в порядке неубывания через один пробел.

Файл: `task3.py`

## Задание 4. Цифры числа

Пользователь вводит целое число `n`. Если число отрицательное, вывести «Ошибка». Для допустимого значения определить количество цифр и их сумму.

Файл: `task4.py`

## Задание 5. Таблица расстояний

Пользователь вводит целое число `n` от 1 до 10 включительно. При выходе за этот диапазон вывести «Ошибка». Построить таблицу расстояний между каждой парой точек с целочисленными координатами от 0 до $n - 1$.

Файл: `task5.py`
