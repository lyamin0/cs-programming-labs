# Лабораторная работа 5. Циклические алгоритмы

## Задание 1. Обратный отсчет

По заданному целому числу $n$ вывести обратный отсчет от $n$ до 0 с помощью цикла `while`.

Файл: `task1.py`

## Задание 2. Сумма и произведение чисел в диапазоне

По введенным границам $a$ и $b$ вычислить сумму и произведение всех целых чисел на отрезке $[a; b]$.

Файл: `task2.py`

## Задание 3. Анализ показаний температуры

По количеству измерений $n$ и серии вещественных значений температуры подсчитать число показаний ниже нуля, равных нулю и выше нуля.

Файл: `task3.py`

## Задание 4. Таблица умножения

По заданному числу $n$ вывести таблицу умножения на множители от 1 до 10.

Файл: `task4.py`

## Задание 5. Расчет стоимости покупок

По потоку стоимостей покупок (до окончания ввода) вычислить количество покупок, их общую стоимость и среднюю стоимость одной покупки.

Файл: `task5.py`

## Задание 6. Треугольник Паскаля

Сгенерировать первые $n$ строк треугольника Паскаля и подсчитать суммарное количество нечетных элементов в построенной числовой пирамиде.

Файл: `task6.py`
