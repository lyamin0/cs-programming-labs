# Лабораторная работа 3. Обработка строк

## Задание 1. Разбор кода документа

Извлечь категорию, год и номер из строки формата `AAA-NNNN-NNNN` с помощью срезов. Вывести номер в обратном порядке.

Файл: `task1.py`

## Задание 2. Форматирование имени

Вывести фамилию с первой буквой в верхнем регистре и остальными в нижнем, затем инициалы имени и отчества в верхнем регистре.

Файл: `task2.py`

## Задание 3. Очистка номера телефона

Удалить из номера телефона символы `+`, пробелы, скобки и дефисы.

Файл: `task3.py`

## Задание 4. Разбор записи о поезде

Разделить строку формата `номер;откуда;куда;время;цена` на поля и вывести оформленную запись с ценой в два знака после запятой.

Файл: `task4.py`

## Задание 5. Проверка идентификатора

Вывести длину строки и результаты проверок: только буквы, только цифры, буквенно-цифровая, содержит дефис.

Файл: `task5.py`

## Задание 6. Формирование пути

Разделить строку из трёх частей через запятую методом `split()` и соединить их символом `/` через `join()`.

Файл: `task6.py`
