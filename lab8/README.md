# Лабораторная работа 8. Функции

## Задание 1. Симуляция посадки космического аппарата

Реализовать консольную пошаговую симуляцию мягкой посадки космического аппарата с процедурной декомпозицией логики на функции:
- `is_valid_command(command)` — проверка корректности команды пользователя (`'0'`, `'1'`, `'2'`, `'exit'`);
- `can_burn(power, fuel)` — проверка наличия достаточного количества топлива для выбранной мощности тяги;
- `simulate_step(height, speed, fuel, power, gravity, thrust_step)` — пересчет параметров движения (высота, скорость, топливо) за один шаг симуляции с учетом силы тяжести и тормозного импульса;
- `get_status(height, speed, safe_speed=2)` — определение состояния полета («В полете», «Посадка успешна» при достижении поверхности с безопасной скоростью $\le 2$, «Авария» при превышении скорости);
- `format_state(height, speed, fuel)` — форматированный вывод параметров телеметрии;
- `main()` — управляющий цикл с интерактивным вводом команд оператора, обработкой внештатных ситуаций и завершением при касании грунта или прерывании миссии.
